Install ChorusClip

Android with Chrome

Open ChorusClip in Google Chrome. Tap ⋮ → Add to Home screen → Install. Chrome may call the menu item Install app.

Open in Chrome

Samsung Internet

If Play Protect shows an older Android version warning, dismiss it and use Chrome to install. If the Chrome button does not open, open Chrome manually and go to chorus-clip.vercel.app.

To stay in Samsung Internet, go back to the homepage and use ☰ → Add page to → Home screen. If offered a choice, pick the shortcut option.

iPhone and iPad

Open ChorusClip in Safari and tap Share → Add to Home Screen.
